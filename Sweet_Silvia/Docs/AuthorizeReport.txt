REPORTE DE AUTORIZACION PARA LA API - SWEET SILVIA

Roles actuales:
- Cliente
- Administrador
- Asistente

Idea general:
- Administrador: controla todo el sistema.
- Asistente: apoya la operacion diaria, pedidos, envios y atencion.
- Cliente: solo gestiona su propia cuenta, carrito, direcciones, pagos y pedidos.

NOTA:
Cuando un endpoint permita Cliente, se debe validar tambien que el recurso le pertenezca.
Ejemplo: un cliente puede ver una orden solo si Order.UserId es igual al userId del token.


1. AUTENTICACION / SESIONES

POST /api/auth/login
Authorize: AllowAnonymous
Uso: iniciar sesion.

POST /api/auth/refresh
Authorize: AllowAnonymous
Uso: renovar access token usando refresh token.

POST /api/auth/logout
Authorize: Cliente, Administrador, Asistente
Uso: cerrar sesion actual.

Authorize: Cliente, Administrador, Asistente
Uso: listar sesiones propias.

GET /api/refresh-tokens/user/{userId}
Authorize: Administrador
Uso: listar sesiones de un usuario.

Authorize: Administrador
Uso: revocar una sesion.

20. REVISION DE PAGO

GET /api/payment-reviews
Authorize: Administrador
Uso: listar revisiones de pago.

GET /api/payment-reviews/payment/{paymentId}
Authorize: Administrador, Asistente
Uso: ver revision de un pago.

POST /api/payment-reviews
Authorize: Administrador
Uso: registrar revision de comprobante. Esta accion aprueba o rechaza el pago.

NOTA:
Payment representa el estado actual del pago.
PaymentReview representa el historial/auditoria de la decision.
Por ejemplo: Payment queda como Approved o Rejected, y PaymentReview guarda el reviewerUserId, fecha, resultado y observacion.
Si aprobar pago descuenta stock, esta accion deberia quedarse solo en Administrador.

RESUMEN POR ROL

Administrador:
- Gestionar usuarios.
- Bloquear usuarios.
- Asignar roles.
- Gestionar roles.
- Gestionar categorias.
- Gestionar colecciones.
- Gestionar productos, variantes e imagenes.
- Gestionar cupones y restricciones.
- Ver uso de cupones.
- Ver y cambiar ordenes.
- Aprobar o rechazar pagos.
- Gestionar metodos de pago.
- Gestionar couriers, envios y tarifas.
- Ajustar stock.

Asistente:
- Ver usuarios basicos.
- Ver ordenes.
- Ver pagos y comprobantes.
- Ver revisiones de pago.
- Crear y editar productos.
- Crear y editar variantes de producto.
- Crear, editar y desactivar departamentos, provincias y distritos.
- Gestionar envios.
- Registrar eventos de envio.
- Ver tarifas y couriers.
- Ver historial de stock por variante.
- Agregar o editar imagenes de producto si se permite.
- No bloquear usuarios.
- No asignar roles.
- No eliminar/desactivar productos.
- No eliminar/desactivar variantes de producto.
- No aprobar/rechazar pagos si eso descuenta stock.
- No ajustar stock manualmente.

Cliente:
- Registrarse.
- Iniciar sesion.
- Ver y editar perfil propio.
- Gestionar carrito propio.
- Gestionar direcciones propias.
- Aplicar cupones.
- Crear orden.
- Crear pago pendiente.
- Subir comprobante.
- Ver sus ordenes.
- Ver sus pagos.
- Ver sus envios.
- Ver seguimiento de sus envios.
